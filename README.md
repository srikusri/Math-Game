# 🏴‍☠️ Math Treasure Hunt — CBSE Grades 5–8

A fun pirate-themed **math game** that teaches CBSE Grade 5–8 topics through a
treasure hunt across the seven seas. Kids pick their grade, sail from island to
island (one CBSE topic each), answer freshly generated questions, collect gold
coins, and open treasure chests!

**100% static** — plain HTML/CSS/JS, zero dependencies, zero build step.
Perfect for GitHub Pages.

## ✨ Features

- 🎂 **Grades 5, 6, 7, 8** — 6 CBSE topic islands per grade (24 topics total):
  - Grade 5: Number Map · Multiply Dock · Fraction Cove · Decimal Bay · Shape Lagoon · Measure Peak
  - Grade 6: Integer Iceberg · Fraction Falls · Decimal Deck · Ratio Reef · Algebra Anchorage · Geometry Gardens
  - Grade 7: Integer Storm · Equation Cove · Percent Plateau · Profit & Plunder · Angle Atoll · Exponent Expedition
  - Grade 8: Rational Rapids · Linear Lagoon · Square-Cube Cove · Power Peak · Mensuration Meadow · Factor Fortress
- 🔁 **Non-repeating dynamic questions** — every question is generated by a
  procedural generator, and the game never shows the same question twice.
  Infinite practice, zero boredom.
- ✏️ **Captain's Sketch Pad** — a built-in SVG drawing tool (pen, eraser, line,
  box, circle, stickers, undo, save as .svg) for rough work: number lines,
  shapes, angle diagrams, anything!
- 🎨 **Dynamic SVG graphics** — pirate captain, parrot buddy, treasure chests,
  islands, ships, angle diagrams, fraction pies, area grids… all hand-drawn
  SVG generated on the fly (no image files).
- 💰 Coins, streak bonuses, hints, and a Grand Treasure victory screen.
- 💾 Progress saves automatically in the browser (localStorage).
- 🔊 Cute sound effects via WebAudio (toggleable).
- 📱 Responsive — works on phones and tablets.

## 🚀 Host it on GitHub Pages

1. Create a new repository on GitHub (e.g. `math-treasure-hunt`).
2. Upload/push these files to the repository (keep `index.html` at the root):
   ```bash
   git init
   git add .
   git commit -m "Math Treasure Hunt"
   git branch -M main
   git remote add origin https://github.com/<your-username>/math-treasure-hunt.git
   git push -u origin main
   ```
3. Go to **Settings → Pages** → under "Build and deployment", set
   **Source: Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Wait ~1 minute, then open:
   `https://<your-username>.github.io/math-treasure-hunt/`

That's it — no build, no npm, no server.

## 🧪 Running the tests

The question generators are covered by a unit-test suite that **parses every
generated question and independently recomputes the answer** (9,600+ questions
per run), checks MCQ integrity, guarantees an island's 5 questions never
repeat, and tests the answer-matching rules:

```bash
node tests/unit-tests.js
```

If you add or change a generator, add a matching verifier in the `VERIFIERS`
map in `tests/unit-tests.js` — it re-derives the answer from the question text
with independent arithmetic, so generator bugs (like a place value computed
from the wrong digit) get caught automatically.

## 🖥️ Run locally

Just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## 🧩 Project structure

```

css/style.css     # pirate theme, animations, responsive layout
js/rng.js         # random + fraction/number helpers
js/art.js         # dynamic SVG art library (characters, diagrams, map)
js/questions.js   # 24 CBSE question generators (grades 5–8)
js/doodle.js      # SVG sketch pad (pen/shapes/stickers/undo/save)
js/game.js        # game engine: map, quiz flow, coins, hints, saving
.nojekyll         # tells GitHub Pages to serve files as-is
```

## 🎓 Learning notes

Every question includes a **hint** that teaches the underlying method
(BODMAS, angle sums, fraction LCM, SI = PRT/100, etc.), and wrong answers
are met with encouragement and a second try — mistakes are part of the hunt!
